# Code font

`Hack-Regular.ttf` is the unmodified font distributed in the pinned `epaint_default_fonts` 0.35.0 Cargo package. `LICENSE-Hack.txt` preserves its Source Foundry, DejaVu and Bitstream notices. The PDF embeds a subset for selectable, monospaced Rust code. Body text uses the Bitstream Vera fonts supplied by ReportLab.
